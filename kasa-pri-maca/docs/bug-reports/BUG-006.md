# BUG-006: Текстът в плочките на масите се припокрива и се къса по средата на думата на 320 px

| Поле | Стойност |
|---|---|
| Сериозност | Средна |
| Приоритет | P2 |
| Статус | Поправен |
| Дата | 2026-10-20 |
| Среда | Chromium мобилен изглед (360/320 px) и Chrome на Samsung Galaxy A55, тестов режим |
| Свързан тест случай | TC-052 |

## Стъпки за възпроизвеждане
1. Отвори таблото с маси на 320 px
2. Добави бележки с хора и час

## Очакван резултат
Текстът е четлив и не излиза извън плочката.

## Реален резултат
Етикетите се наслагват върху номера и думите се късат.

## Доказателства
Екранни снимки и изход от конзолата от сесиите за тестване (не са качени в хранилището).

## Бележки
Минимална височина на плочката 118 px, хората са „👥 N“, бележката е долу, `.tk` без пренасяне, отделни правила за малки екрани. Поправен. Намерен при визуален одит.
