# BUG-005: Менюто не се зареждаше след презареждане в тестов режим

| Поле | Стойност |
|---|---|
| Сериозност | Висока |
| Приоритет | P1 |
| Статус | Поправен |
| Дата | 2026-10-20 |
| Среда | Chromium мобилен изглед (360/320 px) и Chrome на Samsung Galaxy A55, тестов режим |
| Свързан тест случай | TC-042 |

## Стъпки за възпроизвеждане
1. Влез с тестов вход
2. Презареди страницата

## Очакван резултат
Менюто се показва.

## Реален резултат
Менюто липсва.

## Доказателства
Екранни снимки и изход от конзолата от сесиите за тестване (не са качени в хранилището).

## Бележки
`buildMenu()` е добавена в `initData()`. Поправен. Намерен при тестове след добавяне на редактора на менюто.
