# Тестове

| Файл | Какво проверява | Как се пуска |
|---|---|---|
| `test_site.py` | 18 статични проверки: заглавие/описание, увеличаване на телефон, уникални `id`, `alt` на снимките, имена на бутоните, безопасни външни връзки, всички снимки и вътрешни връзки съществуват, валидни структурирани данни, страница и sitemap за всяка подстраница, коректни данни за новини и документи, актуалност на генерираните блокове | `python -m unittest discover -s tests -v` (от папка `pgpt-lom`) |
| `a11y.mjs` | Достъпност (WCAG 2.0/2.1 A и AA) с axe-core в Chromium, на десктоп и мобилен размер, за 7 изгледа | виж коментара най-горе във файла |

В GitHub и двете се пускат автоматично при промяна в `pgpt-lom/` (`.github/workflows/pgpt-lom-tests.yml`).
Одитът за достъпност засега само съобщава проблеми и не блокира; премахнете `continue-on-error: true`, за да става блокиращ.
