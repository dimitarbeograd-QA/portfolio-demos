# Portfolio demos

Small demo projects I build to practise web development and QA. Each project lives in its own folder, with its own README, tests and, where it makes sense, a live demo.

**Dimitar Beograd** · freelance web developer and aspiring junior QA engineer · Lom, Bulgaria · [DimitTech](https://dimitga4qa.github.io/)

## Projects

| Project | What it is | Live demo | Stack |
|---|---|---|---|
| [wedding-invite](wedding-invite/) | Electronic wedding invitation with an animated sealed envelope, 5 switchable design variants, RSVP form, post-wedding photo and video gallery with moderation, and an admin dashboard. Content is in Bulgarian. | [Open the demo](https://dimitarbeograd-qa.github.io/portfolio-demos/wedding-invite/) | Vanilla HTML, CSS and JS, optional Supabase, Cypress |
| [lom-3d](lom-3d/) | Interactive 3D model of the town of Lom with real terrain, about 9,900 buildings, a satellite ground and a day/night slider, built from open data (OpenStreetMap, Microsoft footprints, Sentinel-2, Copernicus DEM). Content is in Bulgarian. | [Open the demo](https://dimitarbeograd-qa.github.io/portfolio-demos/lom-3d/) | Three.js, vanilla JS, GLSL, Python data pipeline |

## About the demos

- Demo mode keeps RSVPs and uploaded photos in the visitor's own browser only, so nothing is sent to a server.
- Each project's `README.md` explains how to run it and what is tested.
- Fonts are self-hosted and open-licensed (SIL OFL).
